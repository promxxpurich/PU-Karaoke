# คลังฉาก MV — คู่มือเขียนบท `mv.json`

> ไฟล์นี้สร้างอัตโนมัติจาก `static/mv/scenes-*.js` ด้วย `node scripts/mv_catalog.js` — ห้ามแก้มือ

## รูปแบบ mv.json (วางในโฟลเดอร์เพลง คู่กับ lyrics.json)

```json
{
  "v": 1, "title": "ชื่อเพลง", "artist": "ศิลปิน", "credit": "ที่มาของรูป",
  "theme": { "bg": "#0a0a0d", "acc": ["#ff2e4d", "#b06cff"], "light": false, "tr": "cut", "td": 0.35, "lead": 0.06,
             "pals": { "day": {"bg":"..","band":"..","hi":"..","fg":"..","alt":".."} } },
  "images": { "ชื่อรูป": { "src": "frames/f156.jpg", "fy": 0.4, "head": [0.5, 0.25] }, "plate": { "src": "lib/plumeria_alba.jpg" } },
  "intro": { "scene": "lockscreen", "p": { ... } },
  "outro": { "scene": "crtOff", "p": { ... } },
  "gaps":  { "13": { "scene": "interlude", "p": { "img": "..", "text": "♪ ดนตรี ♪" } } },
  "lines": [ { "i": 0, "scene": "tear", "p": { "img": "couple", "word": "คน", "acc": 0 }, "tr": "glitch" },
             { "i": [16, 18], "scene": "ecg", "p": { "word": "จริง" } } ]
}
```

- `i` = ลำดับบรรทัดใน lyrics.json (เริ่ม 0) หรือ `[a, b]` สำหรับฉากหลายบรรทัด — บรรทัดที่ไม่ได้ระบุ ระบบใช้ฉาก `kinetic` ให้เอง
- `p.word` / `p.until` = regex ของคำในบรรทัดที่เป็นจังหวะเอฟเฟกต์ (ไม่เจอ = ใช้สัดส่วนของบรรทัด) · `p.acc` = เลขสีใน theme.acc หรือรหัสสี
- `tr` เปลี่ยนฉาก: cut / fade / wipe / iris / slide / blinds / glitch · `td` = วินาที · `lead` = เข้าฉากก่อนบรรทัดกี่วิ (เพลงเร็ว 0.06 / ช้า 0.4)
- รูป: `frames/fSSS.jpg` = ภาพนิ่งจากคลิป (scripts/mv_prep.py) · `lib/x.jpg` = คลังรูปสาธารณะกลาง (static/mv/lib) · `fy` = จุดโฟกัสแนวตั้ง 0–1 · `head` = ตำแหน่งหัวคน [x, y] 0–1 (ฉาก doodle ใช้)
- ช่วงดนตรีเงียบเกิน 7 วิ ระบบใส่ `interlude` ให้เอง (กำหนดเองได้ใน `gaps` โดยใช้เลขบรรทัดก่อนช่วงนั้น)
- อินโทรยาวเกิน 16 วิ: ฉาก intro เล่น 10 วิแรก แล้วต่อด้วย `interlude` จนถึงบรรทัดแรก (กำหนดเองได้ที่ `introGap`)
- `theme.light: true` = พื้นกระดาษ (ฉากตระกูลภาพเก่า) · ค่าเริ่มต้นธีม: `{"bg":"#0a0a0d","acc":["#ff2e4d","#b06cff","#3fd0ff","#ffd23f"],"tr":"cut","td":0.35,"lead":0.06}`

## หลักการเขียนบท
1. อ่านเนื้อทั้งเพลง หาโครง (ท่อน A / แร็ป / พรีฮุก / ฮุก) — ฮุกที่ซ้ำหลายรอบใช้ชุดฉากเดียวกันแต่เปลี่ยน `acc`/`pal` ทุกรอบ
2. เลือกฉากที่ "ตรงความหมาย" ของบรรทัดนั้น (ดูคำแนะนำในแต่ละฉาก) ไม่ใช่สุ่ม; คำเด็ดของบรรทัดใส่เป็น `word`
3. ดู frames/sheet.jpg แล้วตั้งชื่อรูปตามสิ่งที่เห็น (her / couple / street …) เลือกรูปให้เข้ากับบรรทัด อย่าใช้รูปที่มีตัวหนังสือ/โลโก้ฝังเยอะ
4. ไม่ใช้ฉากเดิมติดกันเกิน 2 บรรทัด (ยกเว้น camcorder ในท่อนแร็ปที่เปลี่ยนรูปทุกบรรทัด)
5. ห้ามแต่งเนื้อเพลงเพิ่ม — ข้อความประกอบ (ชื่อในแชต, ตราประทับ, ป้าย) สั้น ๆ และมาจากเนื้อเพลง

## รายการฉาก

### มือถือ / ความทรงจำ / เมือง (ธีมมืด)

**`lockscreen`** — ฉากเปิด: หน้าจอล็อกมือถือ วอลเปเปอร์เป็นรูป + แจ้งเตือนเด้ง (ชื่อเพลง/ข้อความ) + นับถอยหลังก่อนเข้าเนื้อ
- `img`: รูปวอลเปเปอร์
- `time`: เวลาบนจอ เช่น "23:14"
- `date`: วันที่
- `notes`: [{title, body, img?}] แจ้งเตือน (ค่าเริ่มต้น = ชื่อเพลง)

**`tear`** — รูปคู่ในโพลารอยด์ถูกฉีกครึ่งตรงคำที่กำหนด ครึ่งขวาลอยหายไป — "กลับไปอยู่กับเขา", "แยกทาง", "เลิกกัน"
- `img`: รูปคู่/รูปสองคน
- `word`: คำที่ฉีก (regex)
- `acc`: สีเน้น

**`chat`** — หน้าจอแชตในมือถือ: บรรทัดก่อนหน้าเป็นข้อความฝั่งเรา (ฟ้า) บรรทัดนี้คือข้อความอีกฝ่าย ขึ้น "กำลังพิมพ์…" ก่อน — ประโยคที่เหมือนบทสนทนา/คำพูดของอีกฝ่าย
- `avatar`: รูปอีกฝ่าย
- `name`: ชื่อในแชต (ค่าเริ่มต้น "เธอ")
- `acc`: สีตัวหนังสือ

**`doodle`** — รูปคนในโพลารอยด์เม็ดสกรีน แล้วปากกาวาดลายมือทับ (เขาปีศาจ/มงกุฎ/วงนางฟ้า/หัวใจ/น้ำตา/กากบาท) ตรงคำที่กำหนด ข้อความอยู่ขวา — "ปีศาจ", "นางฟ้า", "ราชา", "ร้องไห้"
- `img`: รูปคน (ตั้ง head [x,y] ในรูปที่ images)
- `kind`: horns|crown|halo|heart|tears|x|scribble
- `word`: คำเริ่มวาด (regex)
- `until`: คำที่วาดเสร็จ (regex, ไม่ใส่ = +0.7 วิ)
- `acc`: สีปากกา

**`slam`** — ตัวหนังสือยักษ์แบบกลิตช์ ทีละวลี (แบ่งตามช่องว่างในเนื้อ) — ท่อนฮุก/ชื่อเพลง/คำเด็ด
- `acc`: สีวลีที่สองเป็นต้นไป
- `label`: ข้อความเล็กมุมซ้ายบน (ไม่ใส่ = ชื่อเพลง)

**`strip`** — แถบรูปตู้สติกเกอร์ 4 ช่อง เลื่อนขึ้น รูปที่กำหนดโดนกากบาท + ตราประทับ ข้อความอยู่ขวา — "ผิด", "ไม่ใช่", ความทรงจำคู่
- `imgs`: รูป 4 รูป
- `word`: คำที่กากบาท (regex)
- `mark`: ลำดับรูปที่โดนกากบาท 0–3
- `stamp`: คำในตราประทับ (เช่น "ผิด")
- `acc`: สีปากกา

**`spotlight`** — ห้องมืด ไฟสปอตไลต์ส่องรูปใบเดียวที่แขวนแกว่ง ฝุ่นลอย — "อยู่คนเดียว", "เหงา", "ไม่มีใคร"
- `img`: รูป (คนเดียว)
- `label`: ข้อความเล็กใต้เนื้อ เช่น "1 คน"

**`stickerWall`** — กำแพงสติกเกอร์ลายมือ (หน้าปีศาจ/หัวใจ/ดาว) ค่อย ๆ เต็มจอ กระพริบตรงคำที่กำหนด — คำซ้ำ/ท่อนฮุกรอบสอง
- `kind`: devil|heart|star|x
- `word`: คำที่จอกระพริบ (regex)
- `acc`: สีพื้น

**`gallery`** — แกลเลอรีรูปในมือถือ ขึ้นหน้าต่าง "ลบรูปภาพ?" ตรงคำที่กำหนดกดลบ รูปหายทีละใบ แล้วขึ้นคำใหญ่ — "Good bye", "ลืม", "ลบ", "จบ"
- `imgs`: รูป 6–12 รูป
- `word`: คำที่กดลบ (regex)
- `big`: คำใหญ่หลังลบ (ไม่ใส่ = ไม่มี)
- `title`: หัวหน้าต่าง (ค่าเริ่มต้น "ลบรูปภาพ 12 รูป?")
- `acc`: สีกรอบ

**`camcorder`** — ภาพกล้องวิดีโอ ● REC: รูปแนวตั้งกลางจอ + พื้นเบลอ + เส้นสแกน + เวลาวิ่ง ใส่ของประกอบได้ — ท่อนแร็ป/ท่อนเล่าเรื่อง (เปลี่ยนรูปทุกบรรทัด)
- `img`: รูป
- `fx`: cash แบงก์ร่วง | dots กำลังพิมพ์ | tint ย้อมสี | bars แท่งเสียง | flare แสงวาบ | crack จอร้าว | rain ฝน
- `word`: คำที่จอร้าว (fx=crack)
- `tint`: สีย้อม (fx=tint)
- `rec`: ข้อความมุมขวาล่าง

**`ecg`** — จอวัดชีพจร: เส้นกราฟเต้นทุกคำที่ร้อง อ่อนลงทีละบรรทัด แล้วหยุดเต้นตรงคำที่กำหนด + "?" ใหญ่ — ใช้กับ 2–3 บรรทัดติดกัน (พรีฮุก, "ไม่มีหัวใจ", "ใจสลาย")  
_บรรทัด: หลายบรรทัด (i: [a, b])_
- `word`: คำที่หัวใจหยุดเต้น ในบรรทัดสุดท้าย (regex)
- `acc`: สีเส้น
- `mark`: ตัวใหญ่จาง ๆ หลังหยุดเต้น (ค่าเริ่มต้น "?")

**`notebook`** — สมุดเขียนเนื้อเพลงด้วยลายมือ ปากกาเดินตามที่ร้อง บนโต๊ะมืด — "เขียนเพลง", "จดหมาย", ท่อนรำพึง
- `title`: หัวกระดาษ เช่น "เพลงรัก #27"
- `img`: รูปจาง ๆ ด้านหลัง (ไม่ใส่ได้)
- `ink`: สีหมึก

**`videoCall`** — หน้าจอวิดีโอคอล: รูปอีกฝ่ายเต็มจอ "กำลังโทร…" + จอเล็กมุมขวา + ปุ่มวางสาย — "โทร", "application", "คุยกัน"
- `img`: รูปอีกฝ่าย
- `pip`: รูปในจอเล็ก
- `name`: ชื่อ
- `on`: สีเนื้อ

**`voiceNote`** — แชตข้อความเสียง: คลื่นเสียงเดินตามที่ร้อง + สติกเกอร์หัวใจเด้งตรงคำที่กำหนด — "ฝากบอก", "ดูแลตัวเอง", คำห่วงใย
- `avatar`: รูปอีกฝ่าย
- `name`: ชื่อ
- `word`: คำที่หัวใจเด้ง (regex)
- `bg`: รูปพื้นหลังเบลอ

**`gridCross`** — ตาราง 10 รูป โดนกากบาททีละรูปตามที่ร้อง + ตัวนับ — "หาอีกสิบก็ไม่เหมือน", "ไม่มีใครแทน", การเปรียบเทียบ
- `imgs`: รูป 5–10 รูป
- `label`: ข้อความตัวนับ เช่น "ไม่มีใครคล้าย"
- `acc`: สีปากกา

**`dissolve`** — รูปในโพลารอยด์ค่อย ๆ สลายเป็นเม็ดปลิวหาย — "ไม่มีความหมาย", "จางหาย", "ลืม"
- `img`: รูป
- `acc`: สีเม็ด

**`crtOff`** — ฉากปิด: จอดับแบบทีวีเก่า (ยุบเป็นเส้นแล้วเป็นจุด) แล้วขึ้นชื่อเพลงแบบกลิตช์ + เครดิต
- `img`: รูปสุดท้ายก่อนดับ

### ภาพเก่า / งานพิมพ์ / ไทย-อีสาน (ธีมสว่าง)

**`titleCard`** — ฉากเปิด: แผ่นภาพ (ลายเส้น + เม็ดสกรีน) ค่อย ๆ ถูกวาดทางซ้าย ชื่อเพลงพิมพ์สองสีทางขวา + กรอบ + นับถอยหลัง
- `img`: รูปแผ่นภาพ (ภาพพฤกษศาสตร์/ภาพเก่า/รูปศิลปิน)
- `sub`: บรรทัดรอง เช่น ชื่อภาษาลาว/อังกฤษ
- `style`: line (ลายเส้น) | photo (รูปจริง)

**`outroCard`** — ฉากปิด: แผ่นภาพ + ชื่อเพลง + เครดิตรูป + ดอกไม้ร่วง
- `img`: รูปแผ่นภาพ
- `petals`: true/false ดอกไม้ร่วง

**`bees`** — แผ่นภาพดอกไม้เม็ดสกรีนทางขวา ผึ้งบินวน แล้วบินหนีตรงคำที่กำหนด ข้อความทางซ้าย — "ไร้ผึ้ง", "หมดกลิ่น", "ไม่มีใครสน"
- `img`: รูปดอกไม้
- `word`: คำที่ผึ้งบินหนี (regex)
- `label`: ป้ายเล็กเหนือเนื้อ เช่น "บทที่ ๑"

**`wordsFall`** — คำที่ร้องจบแล้วร่วงหล่นลงพื้นดินทีละคำ เด้งแล้วกองอยู่ — "ร่วง", "หล่น", "ตกต่ำ", "พังทลาย"
- `img`: รูปพื้นดิน/ทุ่ง (แถบล่าง)

**`heartCrack`** — หัวใจใหญ่ (ลายรูปข้างใน) ร้าวตรงคำที่กำหนด แล้วแยกเป็นสองซีก — "ใจสลาย", "เซาฮัก", "หมดรัก", "เจ็บ"
- `img`: รูปลายในหัวใจ (ไม่ใส่ได้)
- `word`: คำที่ร้าว (regex)
- `acc`: สีหัวใจ

**`letter`** — จดหมายเขียนมือบนโต๊ะ เนื้อเขียนตามที่ร้อง แล้วตราประทับสีแดงกระแทกลงตรงคำที่กำหนด — "บอกลา", "ขอโทษ", "สัญญา", จดหมายถึงใครสักคน
- `to`: หัวจดหมาย เช่น "ถึง… เธอ"
- `stamp`: คำในตราประทับ
- `word`: คำที่ประทับ (regex)
- `img`: รูปจาง ๆ พื้นหลัง

**`shatter`** — ภาพเต็มจอแตกเป็นเสี่ยง ๆ ตรงคำที่กำหนด เศษลอยห่างออก (บรรทัดที่สองตัวหนังสือเซไปมา) — "ใจพัง", "แตกสลาย", "โลเล"; ใช้ได้ 1–2 บรรทัด  
_บรรทัด: 1–2 บรรทัด_
- `img`: รูปเต็มจอ
- `word`: คำที่แตก (regex)
- `sway`: true = บรรทัดที่สองโยกไปมา

**`bloom`** — สองบรรทัด: บรรทัดแรกทั้งภาพเป็นสีเทา ดอกเหี่ยว / บรรทัดที่สองดอกบานทีละดอกตามคำ สีไหลกลับ — "เหี่ยวเฉา…แตกช่อใหม่", "เริ่มใหม่", "ยังสู้"  
_บรรทัด: 2 บรรทัด (เศร้า -> หวัง)_
- `petal`: สีกลีบ
- `glow`: สีพื้นตอนบาน

**`drift`** — ภาพกลางคืนเม็ดสกรีนทอง คำลอยตามสายลมเหมือนกลิ่นหอม/ควัน แสงทองระยิบ — "กลิ่นหอม", "ลอยไป", "คิดถึง", "ฝัน"
- `img`: รูปกลางคืน/ภูมิทัศน์
- `acc`: สีคำที่ร้องแล้ว

**`houses`** — ลายผ้าซิ่นขอบบน-ล่าง + บ้านใต้ถุนสูง 5 หลัง ดอกไม้กระโดดไปผิดหลัง — "ไปผิดบ้าน", "ผิดที่", "หลงทาง" (ลูกทุ่ง/อีสาน)
- `pal`: ชุดสี (theme.pals)
- `wrong`: หลังที่ผิด 0–4 (ค่าเริ่มต้น 3)

**`fog`** — หมอกค่อย ๆ ลอยมาบังคำ ตั้งแต่คำที่กำหนดเป็นต้นไปจางหาย — "มองไม่เห็น", "เลือนลาง", "ไม่ชัดเจน"
- `pal`: ชุดสี
- `word`: คำแรกที่ถูกหมอกบัง (regex)
- `img`: รูปพื้นจาง ๆ

**`wordSlam`** — ทีละคำเต็มจอ พื้นเปลี่ยนสีทุกคำ รัศมีหมุน — บรรทัดสั้นที่อยากเน้นทุกคำ "ความฮักต้องฉักให้เป็น"
- `pal`: ชุดสี

**`mapPath`** — แผนที่เก่า เส้นทางประแดงเดินไป แล้วเลี้ยวผิดทางตรงคำที่กำหนด + กากบาท — "เลือกผิดทาง", "หลงทาง", "เส้นทาง", "ระยะทาง"
- `img`: รูปแผนที่ (lib/map_siam.jpg)
- `word`: คำที่เลี้ยวผิด (regex)
- `pal`: ชุดสีแถบบน
- `dark`: true = มืดลง (ฮุกกลางคืน)

**`sunburst`** — ท่อนฮุกใหญ่: รัศมีหมุน ดอกไม้ยักษ์กลางจอเต้นตามคำ ดอกเล็กโคจร กลีบระเบิดตรงคำที่กำหนด — ฮุก/ชื่อเพลง/ท่อนที่ทุกคนร้องตาม
- `pal`: ชุดสี
- `word`: คำที่กลีบระเบิด (regex)
- `img`: รูปกลางวงกลมแทนดอกไม้ (ไม่ใส่ = ดอกไม้)

**`interlude`** — ช่วงดนตรี (ไม่มีเนื้อ): รูปเม็ดสกรีนทองบนพื้นเข้ม + แท่งเสียงจริงจากเพลง + ข้อความกลางจอ + บรรทัดถัดไป + นับถอยหลัง — ระบบใส่ให้เองทุกช่วงเงียบเกิน 7 วิ
- `img`: รูป (เช่น หมอลำเป่าแคน / วงดนตรี)
- `text`: ข้อความใหญ่ เช่น "♪ ม่วนซื่น ♪"

**`river`** — สายน้ำยามค่ำ คลื่นเส้นทองเคลื่อน ดอกไม้ลอยตามน้ำพร้อมเงาสะท้อน — "ลอยล่อง", "สายน้ำ", "ปล่อยไป", "แม่น้ำ"
- `img`: รูปท้องฟ้า/ภูมิทัศน์ครึ่งบน

**`toss`** — ดอกไม้ถูกโยนทิ้งโค้งข้ามจอ เส้นความเร็ว คำกระเด็นเข้ามาเอียง ๆ — "โยนทิ้ง", "ทิ้งขว้าง", "ไม่เหลียวแล" (บรรทัดสั้น เร็ว)
- `acc`: สีคำ

**`poster`** — โปสเตอร์ให้กำลังใจ: รูปเม็ดสกรีนทางขวา ตราวงกลมหมุนมีข้อความรอบวง ข้อความใหญ่ทางซ้าย — ประโยคปลอบใจ/ยืนยันตัวตน "ยังเป็นฉัน", "อย่าเศร้า"
- `img`: รูป
- `ring`: ข้อความรอบตรา (ลงท้ายด้วย " · ")
- `acc`: สีเน้น

### ทั่วไป + บรรยากาศ (ใช้ได้ทุกธีม)

**`kinetic`** — ทั่วไป: ตัวหนังสือใหญ่เด้งทีละคำบนพื้นสีเรียบ วงแหวนหมุน — ใช้ได้กับทุกบรรทัด (ฉากสำรอง)
- `bg`: สีพื้น (ไม่ใส่ = สีเน้นของช่วง)
- `on`: สีคำที่ร้อง

**`print`** — ทั่วไป: รูปเต็มจอพิมพ์เม็ดสกรีนสองสีซูมช้า + ป้ายเนื้อแบบโปสเตอร์ — บรรทัดเล่าเรื่องที่มีรูปประกอบ
- `img`: รูป

**`sketch`** — ทั่วไป: รูปกลายเป็นลายเส้นดินสอค่อย ๆ ถูกวาดจากซ้ายไปขวา + ลายมือขีดเส้นใต้ — ท่อนช้า/ท่อนเปิดเรื่อง
- `img`: รูป
- `dark`: true = ชอล์กบนกระดานดำ

**`neon`** — ทั่วไป: กลางคืนนีออน รูปจาง ๆ ย้อมม่วง โบเก้ลอย ตัวหนังสือเรืองแสง + กรอบนีออน — เพลงรัก/เพลงกลางคืน
- `img`: รูป
- `glow`: สีนีออน

**`molamPoster`** — ทั่วไป: โปสเตอร์หมอลำ/คอนเสิร์ต — รัศมีหมุนสีจัด รูปในวงกลมกลางบน ตัวหนังสือหนาขอบเข้มเด้งทีละคำ — เพลงสนุก/ลูกทุ่ง/ท่อนฮุก
- `img`: รูปในวงกลม
- `bg`: สีพื้น
- `ray`: สีรัศมี

**`rain`** — หน้าต่างยามฝนตก: เม็ดฝนไหลบนกระจก ไฟเมืองเบลอข้างหลัง (หรือรูปเบลอ) — "ฝน", "น้ำตา", "เหงา", "คิดถึง"
- `img`: รูปหลังกระจก (ไม่ใส่ = ไฟเมือง)
- `tint`: สีไฟ

**`drive`** — ขับรถกลางคืน: ถนนมุมมองไกล เส้นถนนวิ่งเข้าหา ไฟรถสวนทาง เสาไฟผ่าน — "ขับรถ", "ทางกลับบ้าน", "หนีไป", เพลงจังหวะกลาง-เร็ว
- `sky`: สีฟ้า
- `acc`: สีไฟท้าย

**`sea`** — ทะเลยามพระอาทิตย์ตก/กลางคืน: ดวงอาทิตย์หรือดวงจันทร์ แสงสะท้อนบนคลื่น คลื่นซ้อนชั้น — "ทะเล", "คลื่น", "ไกลแสนไกล", เพลงช้า
- `night`: true = กลางคืน ดวงจันทร์
- `acc`: สีท้องฟ้า

**`stars`** — อวกาศ/ท้องฟ้าดาว: ดาวพุ่งเข้าหาจอ คำที่ร้องแล้วกลายเป็นกลุ่มดาวเชื่อมเส้น — "ดาว", "ฟ้า", "ฝัน", "จักรวาล", "ไกล"
- `acc`: สีเส้นกลุ่มดาว

**`confetti`** — ปาร์ตี้: กระดาษสีโปรยตามบีต พื้นสีสด ไฟสปอตกวาด ตัวหนังสือเด้ง — เพลงสนุก/วันเกิด/ฉลอง/ท่อนฮุกเต้น
- `bg`: สีพื้น
- `colors`: รายการสีกระดาษ

**`beatType`** — ตัวอักษรเต้นตามบีตกลองจริง: คำซ้อนเป็นแถวใหญ่ สลับสีขาว-ดำทุกบีต กระพริบ — ท่อนแร็ปเร็ว/EDM/ฮุกที่ซ้ำคำ (ต้องมี mv_beats.json ถึงจะเต้น)
- `acc`: สีเน้น
