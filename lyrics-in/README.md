# ที่วางไฟล์เนื้อเพลง (ใช้ตอนอยากแก้เอง)

ปกติ **ไม่ต้องทำอะไรที่นี่** — ระบบหาเนื้อเพลงพร้อมเวลาให้เองตอนโหลดเพลง
โดยไล่จากแหล่งที่เวลาแม่นที่สุดก่อน

| ลำดับ | แหล่ง | ที่มาของเวลา |
|---|---|---|
| 1 | ไฟล์ในโฟลเดอร์นี้ | คุณกำหนดเอง |
| 2 | ซับจริงของ YouTube **ภาษาของเพลง** | เวลาจากซับตรง ๆ |
| 3 | lrclib.net (synced LRC) | เวลาจาก LRC |
| 4 | description ของคลิป + ถอดเสียง | ระบบจับเวลาให้จากเสียงร้อง |

**ภาษาของเพลง** ถูกตัดสินก่อนทุกขั้น (ไฟล์ `lang.json` ในโฟลเดอร์เพลง): อักษรในชื่อคลิป → เนื้อใน lrclib
→ whisper ฟังเสียงร้อง → แทร็ก ASR ของ YouTube — ทุกขั้นข้างบนใช้ภาษานั้น (whisper ถอดภาษานั้น,
ใช้ซับภาษานั้น ไม่เอาซับที่เป็นคำแปล, คำบรรยายอัตโนมัติภาษานั้น, คำอธิบายคลิปภาษานั้น)
เพลงอังกฤษได้ FA ด้วยโมเดลอังกฤษทุกขั้น (เลือกเนื้อดีที่สุด/ความคลาด/ตรวจ/ไล่สี) ส่วนญี่ปุ่น/เกาหลี/จีน
ยังไม่มีโมเดล FA: ได้เนื้อจากซับ/lrclib/คำบรรยาย แต่ไม่ไล่สีและไม่เทียบอัตโนมัติ
ระบบเดาผิดก็เลือกภาษาเองได้ใน Studio (🌐 ข้างชื่อเพลง) แล้วมันจะหาเนื้อใหม่ด้วยภาษานั้น

ดูได้ว่าเพลงไหนมาจากแหล่งไหนที่คอลัมน์ `src` ของ `WANTED.tsv` กับ `CHECK.tsv`

## เจอเนื้อไม่ตรงตอนร้อง — กดปุ่มบอกได้เลย

ในหน้า remote การ์ดเพลงที่กำลังเล่นจะมีปุ่ม **📝 เนื้อไม่ตรง** เลือกอาการ (ซับขึ้นช้า/เร็ว, พิมพ์ผิด, ขาดท่อน,
ไม่มีเนื้อ, ผิดเพลง) หรือพิมพ์รายละเอียดแล้วส่ง — ระบบ **ไม่แก้เนื้อให้อัตโนมัติ** แต่เก็บเป็นรายงานพร้อมตำแหน่งในเพลง
ไว้ที่ `songs/yt/<เพลง>/lyrics.reports.json` แล้วขึ้นใน Studio เป็นชิป 🚩 / ตัวกรอง "🚩 มีคนแจ้ง"
คนดูแลกดเวลาในรายงานเพื่อข้ามไปฟังจุดนั้น แก้ แล้วติ๊ก "✓ แก้แล้ว"

ตรวจเวลาเนื้อกับเสียงร้องจริงได้จากปุ่ม **🔍 ตรวจเวลาเนื้อ** ใน Studio (วัดด้วย FA ได้คะแนน % + คำแนะนำเลื่อนทั้งเพลง
เก็บไว้ที่ `songs/yt/<เพลง>/lyrics.check.json`) หรือสั่งจากเครื่อง (ตัวนี้ใช้ whisper/auto-caption เป็นไม้บรรทัด):

```
./.venv/bin/python scripts/verify_lyrics.py <videoId>     ตรวจและซ่อม
./.venv/bin/python scripts/verify_lyrics.py --dry-run     ตรวจทุกเพลง ไม่แก้อะไร
```

ทุกครั้งที่เนื้อถูกแทนที่หรือล้าง (บันทึกใน Studio, ระบบเลือกเนื้ออัตโนมัติ, หาเนื้อใหม่, เลิกใช้เนื้อที่แก้เอง)
ฉบับก่อนหน้าถูกสำรองไว้ที่ `songs/yt/<เพลง>/lyrics.edits/` — กดย้อนได้จาก 🕘 ประวัติใน Studio (เก็บ 20 รุ่น)

## เมื่อเพลงไหนเนื้อผิดหรือเวลาเพี้ยน

**ทางที่ง่ายที่สุดคือเปิด Studio** (`http://<เครื่องนี้>:8080/studio` ใส่ PIN ที่ขึ้นตอนเปิดเซิร์ฟเวอร์
หรือดูในไฟล์ `.studio.json`) แก้ข้อความ/เวลาได้ในหน้าเว็บ มีจอพรีวิว แตะตามจังหวะ และให้ AI จับเวลาให้
กดบันทึกแล้ว Studio จะเขียน `lyrics-in/<videoId>.json` ไว้ให้เอง

ถ้าจะวางไฟล์เอง ตั้งชื่อตาม **videoId** (ดูได้จาก `WANTED.tsv`) ไว้ที่นี่ แล้วระบบจะใช้อันนี้แทนทุกแหล่ง

```
lyrics-in/<videoId>.json     ที่ Studio บันทึกไว้ ({"lines":[{"t","d","x"}]}) -> ใช้ตามไฟล์เป๊ะ ชนะทุกแหล่ง
lyrics-in/<videoId>.lrc      มี [mm:ss.xx] นำหน้าแต่ละบรรทัด -> ใช้เวลาในไฟล์เลย
lyrics-in/<videoId>.txt      ข้อความเปล่า 1 บรรทัด = 1 บรรทัดที่จะขึ้นจอ -> ระบบจับเวลาให้
```

เครื่องมือใน Studio ที่ช่วยให้หาเนื้อและจับเวลาได้ดีขึ้น (ใช้เฉพาะใน Studio ไม่ได้อยู่ในการหาเนื้ออัตโนมัติ):

- **🔍 ตรวจเวลาเนื้อ** — วัดด้วย FA (เดิม whisper ตรงภายใน 0.5 วิแค่ ~27% / FA ~80%) ป้ายความมั่นใจบนรีโมท/Studio
  จึงมาจาก FA ทั้งหมด (เกณฑ์ ✅ ≥60% / ⚠️ <30%) — เนื้อที่ FA จับเวลาเองไม่ขึ้นป้าย เพราะเป็นการวัดตัวเอง
- **🔎 หาเนื้อ** — รวมเนื้อจากซับ YouTube, JOOX, NetEase, YouTube Music, LRCLIB, คำอธิบายคลิป
  ให้คะแนนว่าเข้ากับเสียงร้องจริงแค่ไหน แล้วกด "ใช้ข้อความนี้ + เวลา FA" ได้เลย
  (JOOX มีเนื้อเพลงไทยเกือบครบ แต่เวลาเป็นของเวอร์ชันอัลบั้ม จึงควรใช้แค่ข้อความ แล้วให้ FA จับเวลา)
- **🎯 FA (forced alignment)** — จับคู่ตัวอักษรในเนื้อกับเสียงร้องทีละตัวด้วยโมเดล wav2vec2 ภาษาไทย
  วัดกับเพลงที่คนจับเวลาไว้: ตรงภายใน 0.5 วิ ~80% ของบรรทัด (whisper เดิม ~27%) ใช้ ~10 วิ/เพลงครั้งแรก
  แคชไว้ที่ `lyrics-preview/_fa/` ครั้งต่อไปไม่ถึง 1 วิ (สคริปต์: `scripts/fa_align.py`)
- **🗺 ความคลาด** — จุดสีบนแถบคลื่นบอกว่าแต่ละบรรทัดคลาดจากเสียงร้องเท่าไร + เสนอช่วงที่ควรเลื่อนทั้งท่อน
  ท่อนที่ข้อความซ้ำติดกัน (ฮุควนท้ายเพลง) จะขึ้นสีม่วง — เครื่องวัดได้ไม่แน่นอน ควรฟังแล้วแตะจังหวะเอง

เนื้อที่แก้ใน Studio (`src: manual-edit`) จะ **ไม่ถูกเขียนทับ** โดยปุ่มโหลดเนื้อใหม่, การสร้างใหม่ทั้งคลัง
หรือการตรวจอัตโนมัติ (ตรวจแล้วแค่ขึ้นคำแนะนำ) — อยากกลับไปใช้เนื้อจากแหล่งเดิมให้กด
"🗑 เลิกใช้เนื้อที่แก้เอง" ใน Studio (หรือลบไฟล์ `.json` แล้วสั่งสร้างใหม่)

ตัวอย่าง: `lyrics-in/N9bashij_7c.lrc`

- บรรทัดว่าง = เว้นช่วง (เช่นท่อนดนตรี)
- **ระบบจะไม่แก้ข้อความของคุณแม้แต่ตัวเดียว** จัดให้แค่เวลาเท่านั้น

เสร็จแล้วสั่งสร้างใหม่เฉพาะเพลงนั้น:

```
./.venv/bin/python scripts/gen_lyrics.py <videoId>
```

## โหมดคาราโอเกะ (ไล่สีตามที่ร้องจริง)

เลือกได้ที่รีโมท → ⚙️ ตั้งค่าละเอียด → เนื้อเพลงบนจอ → **🎤 คาราโอเกะ**
จอขึ้น 2 บรรทัดคงที่เหมือนเดิม แต่ตัวอักษรเปลี่ยนเป็นสีชมพูทีละกลุ่มอักษรตอนที่นักร้องร้องถึงจริง
ช่วยตอนนักร้องร้องเร็ว — เวลาเริ่มบรรทัดตรงอยู่แล้ว แต่คนร้องตามไม่รู้ว่าถึงคำไหน

- เวลารายตัวอักษรมาจาก FA เก็บแยกที่ `songs/yt/<เพลง>/lyrics.words.json` (ไม่แตะ `lyrics.json`)
- ระบบทำให้เองทุกเพลง: หลังได้เนื้อ+แยกเสียงเสร็จ / เปิดเซิร์ฟเวอร์ (ไล่ทำเพลงเก่า ตอนเครื่องว่าง) /
  เพลงที่อยู่ในคิวห้อง / กดบันทึกใน Studio (แก้แค่เวลา ไม่ต้องทำใหม่ — แก้ข้อความถึงทำใหม่)
- คำอังกฤษไล่สีด้วย: ใช้โมเดลอังกฤษอีกตัว (`facebook/wav2vec2-large-960h-lv60-self`, ~1.2 GB ใน `.cache/hf`)
  จับพร้อมกับตัวไทยในเส้นทางเดียว คำอังกฤษกลางบรรทัดไทยจึงไม่ทับกัน
  (วัดกับบรรทัดอังกฤษที่คนจับเวลา 165 บรรทัด: ไล่สีได้ 147 บรรทัด ตรงภายใน 0.5 วิ 54% / 1 วิ 70% — ท่อนแร็ปยังยาก)
- บรรทัดที่ FA ไม่มั่นใจ (เสียงไม่ตรงข้อความ, แร็ปเร็วมาก, เกาหลี/จีน/ญี่ปุ่น) ขึ้นแบบ 2 บรรทัดธรรมดา ไม่ไล่สีมั่ว
- เวลาบรรทัดใน `lyrics.json` ใช้เป็นหมุด: ฮุคที่วนซ้ำท้ายเพลงจะไม่ถูกไล่สีผิดรอบ
- Studio: ชิป `🎤 คาราโอเกะ x/y บรรทัด`, ปุ่ม "🎤 ทำเวลารายคำ" / "ทำทุกเพลง", พรีวิว "🎤 คาราโอเกะ"
  และขีดสีส้มใต้ก้อนบนแถบคลื่น = จุดที่ร้องแต่ละตัวอักษร (ไว้ดูว่าเวลาบรรทัดควรเลื่อนไปตรงไหน)
- ถ้าลำโพง/ทีวีหน่วงจนสีวิ่งนำหรือตามเสียง ปรับทั้งจอด้วย `?lyroffset=` ที่ URL ของจอหลักได้ (บวก = ช้าลง)

## ระบบเลือกเนื้อดีที่สุดจากทุกแหล่ง (อัตโนมัติ)

ตอนเพิ่มเพลงใหม่ ระบบยังใช้ "ตัวแรกที่เจอ" ตามตารางข้างบนขึ้นจอก่อน (เร็ว) แล้วมีงานเบื้องหลังตามมา:

1. รวมเนื้อจากทุกแหล่ง: ซับ YouTube, คำอธิบายคลิป, คำบรรยายอัตโนมัติ, lrclib, JOOX, NetEase, YouTube Music
2. ให้ FA เทียบทุกตัวกับเสียงร้องจริงของคลิปนี้
3. เปลี่ยนเฉพาะตอนที่ดีกว่าชัดเจน
   - **เลื่อนทั้งเพลง**: เนื้อถูกแต่เวลาเลื่อน (เช่น lrclib ที่ช้า/เร็วไป 2 วิ)
   - **จับเวลาใหม่ด้วย FA**: เวลาที่ whisper/auto-caption เดาไว้ไม่ตรง
   - **เปลี่ยนข้อความ**: เจอเนื้อที่ครบกว่า/ตรงกว่า
     - เนื้อผิดเพลงจะถูกกันด้วยค่าความเข้ากันเฉลี่ย (เพลงผิดได้ราว 14–30 เนื้อถูก 38–72)
     - ซับ YouTube ของคลิปนี้เองต้องแพ้ขาดถึงจะเปลี่ยน

ของเดิมสำรองไว้เสมอ → Studio → 🕘 ประวัติ กดกลับได้ (กลับแล้วนับเป็นเนื้อที่แก้เอง ระบบจะไม่เปลี่ยนอีก)
เหตุผลที่เปลี่ยนเก็บไว้ที่ `songs/yt/<เพลง>/lyrics.best.json` และขึ้นใน Studio (ชิป ✨ / ตัวกรอง "✨ เปลี่ยนอัตโนมัติ")

- ไม่แตะเนื้อที่แก้ใน Studio หรือวางไฟล์เองใน `lyrics-in/` เด็ดขาด
- เปิดเซิร์ฟเวอร์แล้วจะไล่ทำเพลงเก่าที่ยังไม่เคยเทียบตอนเครื่องว่าง (เพลงในคิวห้องได้ก่อน)
- ปุ่มใน Studio: "✨ เลือกเนื้อดีที่สุด" (เพลงนี้) / "ทุกเพลง"
- ทดลองกับเพลงที่คุณเคยแก้เวลาเองใน Studio: ระบบเลือกได้เวลาตรงกับฉบับที่คุณแก้เฉลี่ย 97% (ก่อนหน้า 48%)
- ตั้งใจไม่มี "ขยับรายบรรทัด": เคยลองขยับบรรทัดที่ FA เห็นต่าง 0.5–1.5 วิ ไปตาม FA แล้ววัดกับ 20 เพลงที่คุณจับเวลาเอง
  ความตรงลดจาก 97% เหลือ 92% = ตรงนั้น FA ผิดเอง ไม่ใช่คน

## เปลี่ยนคีย์เพลง (รีโมท → ⚙️ ตั้งค่าละเอียด → 🎹 คีย์เพลง)

เลื่อนได้ −6 ถึง +6 ครึ่งเสียง ทั้งดนตรีและไกด์เสียงร้องพร้อมกัน จังหวะเท่าเดิม
- ใช้ได้เฉพาะเพลงที่แยกเสียงแล้ว (ทำจากสเต็ม) — ครั้งแรกของแต่ละคีย์ระบบเตรียมไฟล์ ~10 วิ แล้วสลับให้กลางเพลงโดยไม่สะดุด
- ไฟล์คีย์เก็บไว้ที่ `songs/yt/<เพลง>/vocals.k+2.m4a` / `no_vocals.k+2.m4a` (ถูกลบตอนแยกเสียงใหม่)
- ใช้ `pedalboard` (Rubber Band) — ถ้าไม่มีจะใช้ ffmpeg แทน (คุณภาพต่ำกว่า)
- กลับเป็นคีย์เดิมเองทุกเพลงใหม่; จอหลักขึ้นชิป 🎹 ได้ถ้าเลือกไว้ในตั้งค่าจอ

## ตั้งค่าหน้าจอหลัก + เพลงที่กำลังเล่น (ใน Studio)

Studio มีแท็บบนหัวเว็บ 3 แท็บ:
- **🎵 เพลงทั้งหมด**: หน้าแก้เนื้อ/ซ่อมเพลงแบบเดิม
- **▶ กำลังเล่น & คิว**
  - เห็นว่าเนื้อที่ขึ้นจอของเพลงที่เล่นอยู่และทุกเพลงในคิวมาจากแหล่งไหน
  - กด **🔄 เปลี่ยนแหล่งเนื้อ** เพื่อเทียบทุกแหล่งกับเสียงร้องแล้วกดใช้ได้เลย จอหลักเปลี่ยนตามทันที
  - บันทึกเป็นเนื้อที่เลือกเอง (ระบบอัตโนมัติไม่เปลี่ยนทับ ย้อนได้ใน 🕘 ประวัติ)
- **📺 หน้าจอหลัก**: บันทึกเองทุกครั้งที่ปรับ และมีพรีวิวจำลองข้าง ๆ
  - แถบชื่อเพลง: เปิด/ปิด, ซ่อนเองหลังเริ่มเพลง N วิ, ชื่อคนร้อง, ♪ ● ● ● นับถอยหลัง 3 วิก่อนเข้าท่อน (อินโทร/หลังช่วงดนตรี)
  - สถานะหลังชื่อเพลง: ไกด์ / เสียงรวม / ดนตรี / ที่มาเนื้อ / เพลงถัดไป
  - เนื้อเพลง: ขนาด, สีตัวอักษร, สีไล่คาราโอเกะ, ความสว่างบรรทัดที่ยังไม่ถึง, พื้นหลังใต้ซับ, เงา/ขอบ, ยกซับขึ้น
  - มุมจอ: QR (+ขนาด), เวลาเพลง, การ์ด "ต่อไป", การ์ด "เพิ่มเข้าคิว"
  - รูปมุมขวาบน: อัปรูปอะไรก็ได้ ระบบครอปกลางเป็น 1:1 ให้ + เลือกแสดง/ขนาด
  - ข้อความหน้าจอว่าง

ค่าเก็บไว้ที่ `tv.json` และรูปที่ `.tv/logo.png` ในโฟลเดอร์โปรเจกต์ (ลบทิ้ง = กลับเป็นค่าเริ่มต้น)

## คำสั่งที่ใช้บ่อย

```
./.venv/bin/python scripts/fetch_subs.py        ดึงซับ YouTube ย้อนหลังให้เพลงเก่า
./.venv/bin/python scripts/gen_lyrics.py        สร้างเนื้อ+เวลาใหม่ทุกเพลง
./.venv/bin/python scripts/gen_lyrics.py --skip-done   เฉพาะเพลงที่ยังไม่มี
./.venv/bin/python make_wanted.py               อัปเดต WANTED.tsv
./.venv/bin/python lyrics_check.py              ตรวจคุณภาพทุกเพลง -> CHECK.tsv
./.venv/bin/python scripts/verify_lyrics.py     ตรวจกับเสียงร้องจริงแล้วซ่อม
```
